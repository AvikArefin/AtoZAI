# Transformer   
The original attention is all you need paper introduces the "Multi-head Self Attention" Mechanism. But it also uses some previous well stablished architectures.   
   
Transformer = Embedding + Encoder + Embedding + Decoder    
Where,   
Encoder is,   
(Multi-Head Self Attention + Residual Connection) → Layer Norm1 → (Feed Forward Network + Residual Connection) → Layer Norm2   
   
   
In this video you will learn,   

How attention works   
How multi-head attention works (using attention)   
How the transformer works (using multi-head attention and encoder decoder architecture)   
How Language Models work (Using multi-head attention and the decoder)
