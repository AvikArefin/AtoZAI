# Selective State Space Model   
Let's talk about the Selective SSM. This is another architecture that has been growing popularity in recent years that does not use any attention mechanism at all. Instead it uses State Space Modeling.   
Although SSM is a known topic in the engineering space, specifically aerospace, the Selective SSM, specifically still primarily is known by its application: the Nvidia created Mamba Large Language Model.
